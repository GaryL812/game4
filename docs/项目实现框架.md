# 项目实现框架

## 1. 当前首关

原创主题“薄荷天际线”，34 个屋顶，总路程 958.5 米。基础速度 11 米/秒，熟练路线通过加速板可约 62 秒完成；未利用跳板的基础路程约 87 秒，碰撞和复活会增加用时。横向移动连续，最多可移至 ±7.8 米，越过屋顶侧缘会掉落。

7 名选手共用确定性赛道与规则，包含玩家和 6 名 AI。AI 速度从 10.74 到 11.39 米/秒，策略分为入门、常规、熟练三个梯度：前方障碍扣分、跳板加分，并保留少量决策随机性。每名选手使用独立固定随机种子，便于复测。

屋顶边缘通过赛道足迹查询自动触发跳跃，重力和竖直速度模拟落地。这个版本使用解析几何采样代替每名角色每帧的物理射线，适合直线模块化首关。若加入弯道、任意旋转地形或复杂斜坡，需要扩展赛道坐标系或换成射线/扫掠检测，不能直接沿用当前 Z 轴距离排名。

## 2. 代码职责

| 模块 | 职责 |
|---|---|
| `main.gd` | 状态切换、开局、镜头、排名、结算与性能采样 |
| `track_data.gd` | 模块布局、平台查询、障碍/金币/跳板数据、检查点 |
| `runner.gd` | 玩家/AI 共用运动、自动跳跃、碰撞、复活、动画切换 |
| `world.gd` | GLB 实例化、可见范围控制、金币/粒子 MultiMesh 批量绘制 |
| `hud.gd` | 原生矢量 UI、竖横屏布局、触摸命中、商店/任务/榜单 |
| `save_data.gd` | 本地存档、金币、皮肤、每日奖励、本机最佳纪录 |
| `platform.gd` | Godot 与 JS 的原生能力边界、广告结果和后台暂停 |
| `audio.gd` | 4 个复用音源、轻量 MP3 循环与提示音 |
| `tools/wechat/` | 原生 wx API 桥接与开放数据域 |

状态：主页 → 3秒倒数 → 竞速 → 结算；竞速可暂停，掉落后进入复活选择页。免费检查点复活立即可用；配置广告后，可完整观看激励视频回到掉落附近的安全平台。比赛奖励在进入结算时入账一次；广告双倍奖励采用单局幂等标记，重复回调不重复发奖。

## 3. 美术与生产

所有 3D 几何均由 `tools/create_assets.py` 在 Blender 中生成，米制单位、1单位=1米、角色约1.8米。GLB 采用 +Y 向上、+Z 面朝前；纯顶点色、单材质、无纹理贴图。每个模型同时保留压缩 `.blend` 源文件，统计见 `art/asset_manifest.json`。

| 分类 | 资产 |
|---|---|
| 角色 | 基础火柴人、头带款、胸带款，196/208/208 三角面 |
| 动画 | Run、Jump、Land、Flip、Hit、Celebrate；每款均带7骨骼绑定 |
| 可拆配饰 | 帽子、背包、莫西干发型、王冠、耳机 |
| 地形 | 宽/窄/短屋顶、抬高屋顶、转角平台、斜坡模块 |
| 交互 | 黄色跳板、箱体、墙、栏杆、金币、检查点、终点拱门 |
| 城市 | 水塔、空调、烟囱、吊车、远景建筑块 |
| 特效 | 地面投影片、粒子方块；跳跃/加速/拾取/冲线共用20粒子池 |
| UI | Godot 矢量绘制按钮、卡片、进度和排名，无位图依赖 |
| 字体 | Noto Sans SC 的中英文字形子集，600/850字重，SIL OFL |
| 音频 | 程序合成的5类提示音及12秒循环，统一MP3 |

目前全套 28 个模型共 2096 个唯一三角面；单角色 ≤208，单场景模块 ≤120，低于给定上限。完整资产数量与字节数以构建清单为准。斜坡和转角已提供美术模块，当前首关只使用平面直线路线，尚未实现转向竞速。

顶点色在 Godot 运行时统一启用 `vertex_color_use_as_albedo`。若将 GLB 单独拖入另一工程，应为材质勾选该选项。角色用单材质整体乘色；配饰装在角色可视节点上，当前不随头骨单独变形。

UI 使用引擎绘图而不是 Blender 位图，以避免字体与多分辨率 UI 纹理占包；3D 资产完全来自 Blender。背景使用低面数楼体而非贴图面片，便于保持俯视镜头的空间感。高级后处理、实时阴影及大纹理均未启用。

## 4. 微信适配

- 首包：适配器、加载界面、配置、原生桥接、开放数据域。
- `engine` 分包：社区适配的 WASM/JS 引擎与本关 PCK（沿用模板的 `empty-tips.bin` 文件名）。
- 同一资源包内含本关和全部轻量皮肤。将来内容增长时，再通过社区 `godot_subpack_runtime` 生成具备依赖清单的 PCK 分包；当前没有伪造空皮肤包或未实现的远程加载流程。
- `JavaScriptBridge` 访问 `SkylinePlatform`，在原生环境调用 wx 存储、分享、视频、云存储与开放数据域接口。
- 桌面使用 `user://skyline_save.json`；微信优先 `wx.getStorageSync/setStorageSync`。每日任务按 UTC+8 日期刷新，JSON 数值读取时归一化为整数。
- 广告位缺失、加载失败、提前关闭均不奖励。没有“点击分享即验证成功”的奖励逻辑；分享面板无法证明真实分享完成。
- 好友数据只在开放数据域中读取，主域仅把共享画布合成到屏幕。当前只实现好友排行和本机榜，没有全球联网排行榜或防作弊服务器。
- 微信使用原生触摸流，桌面才启用鼠标模拟触摸。切后台自动暂停，回来后由玩家继续。
- 竖/横屏分别导出两个 `deviceOrientation` 配置，UI 根据视口比例调整布局，不声称微信运行中可随意旋转屏幕。

## 5. 性能设计

1. Compatibility / WebGL2，无实时阴影、无屏幕空间效果、无复杂材质；方向光 + 环境光 + 简单雾。
2. 屋顶只保留玩家后35米、前82米的绘制窗口，道具前72米，金币前65米；AI 远离镜头70米后隐藏，但仍计算竞赛进度。
3. 金币与20个固定粒子分别通过 MultiMesh 合并绘制。角色共用导入网格、骨骼结构和动画资源。
4. 碰撞使用平台足迹和障碍 AABB 查询，不引入动态刚体或大批 Area3D。
5. 游戏开始时创建场景对象，竞赛期间不反复创建/销毁障碍与粒子。UI StyleBox 缓存复用，音源池复用；菜单切换允许实例化角色，便于清理单局状态。
6. 设备标记低端时，3D 渲染分辨率降至75%、关闭粒子。连续3次低于29帧时降至70%，UI仍保持原分辨率。
7. 打包脚本实际统计主包字节并对4MiB硬门槛报错，模板下载固定版本及SHA256，避免上游静默替换。

这些是实现与实测范围，不构成低端手机性能认证。完整手机验收矩阵与测量边界见性能报告。

## 6. 后续扩展位置

新增直线关卡可将 `TrackData` 的常量和布局移到数据资源；本版先保证一个关卡完整闭环。任意弯道需要引入路径弧长和局部横向坐标，同时改动角色前进方向、摄像机和平台采样。竞技服务器、全球榜和广告安全校验可通过独立 HTTPS 后端扩展，不把 AppSecret 放入客户端。
