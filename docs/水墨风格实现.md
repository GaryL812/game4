# 水墨山海 · 场景与材质实现

本版沿用三路高低平台的几何与碰撞数据，将表现层统一为“云栈烟岚”。角色操作、NPC竞赛进度、检查平台高度与免费就近复活规则不变。

## 资产与视觉

| 内容 | 当前实现 |
|---|---|
| 四种平台 | 青石板、木栈道、屋檐、石桥，各为48/120/56/128三角面 |
| 障碍 | 竹篓82面、屏风69面、铜铃112面，复用原障碍尺寸与减速规则 |
| 踏板 | 墨痕84面、云纹144面，保留箭头辨识度、祥云曲线与少量暖金边 |
| 场景装饰 | 亭台90面、古塔246面、竹丛138面 |
| 远景 | 6层山形网格，每层48面；雾卡批量绘制，最多6张 |
| 主角 | 433面斗笠浪客，9骨骼和8套动画，灰袍保留，皮肤只改飘带配色 |
| NPC | 简化人体，墨色Shader统一边缘，保留少量颜色差异以便识别 |
| 界面 | Noto Serif SC宋体子集、方形宣纸卡片、朱砂印章、卷轴展开 |

所有新增模型由 `tools/ink_scene_assets.py` 在Blender生成，主入口仍为 `tools/create_assets.py`；GLB与 `.blend` 都可重复重建。源文件被Windows占用时保存到相邻的 `_generated.blend`，保留正在打开的文件。

## Shader分工

- `ink_world.gdshader`：读取顶点色和128²可重复纸纹，生成青石错缝、木纹、瓦片、墨色边缘及干笔起伏。使用简化无光照着色，无屏幕采样、无实时阴影。
- `ink_mountain.gdshader`：山形渐隐与湿墨颗粒，底部淡入纸色；各层通过远近与高度产生山水层次。
- `wanderer.gdshader`：通过视线夹角压暗边缘，并对高频纹理做飞白；浪客衣袍保留原色，NPC按低饱和墨色乘色。
- `ink_particles.gdshader`：共享纸纹与公告板矩阵，用极少量四边形模拟墨滴、烟墨与淡墨扩散。
- `paper_overlay.gdshader`：一次轻薄纸纹叠加，无屏幕读取；UI与3D共用同一张128×128灰度PNG。

纸纹总纹理面积16384像素，开启重复采样。没有引入大尺寸山水贴图、SSAO、SSR、景深或多层描边后处理。

## 平台高度契约

平台源模型行走面为本地Y=8.2。场景把节点放在基底-16，传入 `platform_span=赛道高度+16`。Shader保留上层栏杆与屋檐的尺寸，将下层结构拉伸至所需高度；因此地板的最终世界高度严格等于跑酷数据中的高度。每个网格更新AABB，避免Shader位移后被错误剔除。回归测试检查全部64处平台的高度一致性。

## 水墨反馈与性能

跳跃和落地抛出墨滴；加速时每0.09秒复用一个烟墨实例形成拖尾；碰撞用两团快速扩散的淡墨；冲线展开纸卷，再显示朱砂通关印章。粒子池总量固定20，不在竞赛中反复创建、删除节点。

低端机关闭动态墨迹，将山体减少为4层、雾层减少为3张，并降低3D分辨率；UI维持原分辨率。引擎帧率上限60。具体桌面预算实测见 `性能测试报告.md`，低端安卓和微信真机帧率仍需连接设备验证。
