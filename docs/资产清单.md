# 正式首关资产清单

当前游戏只加载下列 12 个 GLB，编辑源文件位于 `art/<名称>.blend`。使用 `tools/create_assets.py` 可重新导出这些已定稿模型；不会生成旧角色或历史场景。

角色使用 `scripts/paper_runner.gd` 驱动的分部位贴片动画，三套图集为 `assets/textures/paper_runner*.png`。原画保留在 `jiarui/人物贴图/`，不进入游戏包。

远山、古建、竹叶、瀑布与云雾共用 `assets/textures/ink_scenery.webp` 图集；对应原画及平台底纹保留在 `jiarui/`，该目录通过 `.gdignore` 排除导入。终点使用 `assets/ink_bg/finish_gate.png` 贴片。

平台使用 `ink_world.gdshader`、`paper_grain.png` 与 `ink_stone.webp`；斩击和拖尾使用 `assets/ink_fx/`。界面素材为 `progress_scroll_clean.png` 和 `energy_bar.png`。字体为 Noto Serif SC 子集 `ink.ttf`、`ink_bold.ttf`；六个 MP3 音频及相关授权文件保留。

旧火柴人、浪客骨骼试稿、旧门模型、城市装饰、重复背景原图和旧 UI 素材已从正式资源加载和游戏导出中排除；原文件因自动审批拦截尚未删除。模型唯一三角面总和不是单帧渲染统计，手机性能需真机测量。
