# 微信小游戏打包与联调

## 生成游客测试包

已经生成的工程位于 `build/wechat-portrait` 和 `build/wechat-landscape`。在微信开发者工具选择“小游戏”，导入对应目录。无正式 AppID 时选择游客模式；游客模式的登录、广告、云存储和好友榜能力受限。

重建使用 PowerShell 7：

```powershell
./tools/fetch_wechat_template.ps1
./tools/build_wechat.ps1
./tools/build_wechat.ps1 -Orientation landscape
```

脚本下载的社区模板版本为 `minigame4.7.0.8.tpz`，来自 [godothub Release 4.7](https://github.com/godothub/godot-minigame/releases/tag/4.7)。这是发布文件名，不应据此将项目编辑器版本改成4.7.0；当前工程实际使用 Godot 4.7.2。模板 WASM 包含3D节点及网格模块，但仍需要实际微信端验证兼容性。

固定模板 SHA256：`6E9938EC4F8DE0CD9B693A1D851A6B361A7397D6F3EE6A6DE4909B053BAC8A23`。

Godot 命令行先导出 `.pck`，再改名为模板约定的 `engine/empty-tips.bin`。不能直接把 `.bin` 传给官方 Web 平台的 `--export-pack`，因为官方导出器会拒绝该扩展名。

## 配置正式身份

```powershell
./tools/build_wechat.ps1 -AppId '你的AppID' -RewardAdUnitId '你的激励视频广告位ID'
```

也可直接编辑输出目录的 `skyline-config.js` 和 `project.config.json`，但下次重建会覆盖输出配置。请把真实 AppID 与广告位 ID 通过参数保存到自己的构建环境；不需要、也不能在客户端填写 AppSecret。

`game.json` 中声明 `engine/` 为分包，`open-data/` 为开放数据域。默认固定标准 WebGL2；对特定设备验证通过后，可修改 `glx-config.js` 试用微信 GLX。不能在引擎运行中切换已有上下文。

## 账号能力联调

| 能力 | 接入位置 | 验证点 |
|---|---|---|
| 触摸 | 模板输入适配 + `main.gd` | 轻点、连续滑动、多指不抢主指、松手、左右边缘掉落 |
| 本地存储 | `SkylinePlatform.getStorage/setStorage` | 退出重新打开保留金币和皮肤，写入失败提示 |
| 激励视频 | `showRewardAd` | 完整观看才发奖，提前关闭/失败不发奖，重复回调不重复发奖 |
| 分享 | `shareAppMessage` | 显示正确标题，取消后也不发分享奖励 |
| 成绩上报 | `setUserCloudStorage` | 只上报更短用时，单位毫秒 |
| 好友榜 | `open-data/index.js` | 正式登录账号，至少两位有成绩的好友，顺序与关闭操作 |
| 生命周期 | `wx.onHide` | 切后台暂停，广告回来保持正确状态 |

没有正式身份时，按钮会明确说明能力不可用，或由 wx 返回失败。代码不会生成虚假的好友排行与广告成功结果。

## 发布前剩余工作

本机未检测到已安装的微信开发者工具，且当前没有正式 AppID、广告位 ID、连接的测试手机。因此本交付是**可导入的游客测试工程**，未宣称已经微信编译通过、真机稳定30帧或审核通过。

正式发布前需使用你自己的小游戏账号完成：开发者工具编译、低端安卓与iOS真机首启/热启、触摸/广告/好友榜/存档验证、后台高性能能力配置、包体分析和平台审核。模板的 WASM 压缩包约8MB，解压后约66MB；首包小不代表引擎内存占用小，内存峰值也必须真机测量。

资源分包扩展应采用模板对应的运行时与依赖清单；当前首关资源全部放在 `engine` 分包，不依赖任何外部 CDN 或未配置的服务器。
